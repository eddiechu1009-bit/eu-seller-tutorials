why this tool

歐洲站的門檻，不在開帳號，在開帳號之前。

美國站你帶著一張公司登記和一張 credit card 就能開。歐洲不行 — 稅務、包裝回收、產品安全、GPSR、EPR 每一條都能讓你的 Listing 被下架，甚至帳號被停。

01

把多國合規一次列齊

DE / FR / IT / ES / UK 五國各自要什麼？VAT、EORI、EPR、WEEE、包裝註冊的要求各國不同，工具會依你勾選的國家只顯示需要的項目。

按國家過濾
02

依品類自動帶出安規

賣 3C 要 CE / UKCA；賣食品接觸要 LFGB；賣玩具要 EN71；賣電池要 UN38.3。工具內建 20+ 品類的認證對應表，選了品類自動產生。

品類驅動
03

把 2026 激勵方案量化

EU4 返利 €42,000 + FBA 抵扣 €160 + 廣告 credit €750 + Vine + 優惠券，外加 UK 獨立再一份。沒看清楚就等於送錢給 Amazon。

EU4 / UK split
「開歐洲站最浪費的不是錢，是時間。少一張證明、漏一個包裝註冊，整批貨卡在海關兩週，FBA 排隊重來。」 — Eddie Chu · Amazon EU Sr. BDM

module b · step-by-step wizard

分頁 B · 開站全流程

如果「準備清單」是菜單，那「開站全流程」就是把上菜順序排好給你看。一步步從「決定公司主體」到「第一筆訂單出貨」。

PHASE 01 · 前置決策

公司主體、銀行帳戶、商標

用台灣公司 or 香港公司申請？用 Payoneer 還是 WorldFirst？商標要在申請前就動手，因為 EUIPO 審查要 4～6 個月。

PHASE 02 · 註冊帳號

Seller Central 註冊 + KYC 驗證

聯繫你的帳戶經理（AM）協助申請專屬註冊連結，享有新賣家對接資源。註冊過程走一套身份、地址、信用卡、電話視訊驗證。準備好英文版的公司登記和水電帳單，視訊時鏡頭對著身分證。

PHASE 03 · VAT + EORI

稅號申請同步啟動

EU4 各會員國 VAT 分別跟當地稅局申請，UK VAT 跟 HMRC 申請，兩套分開但流程類似。EORI 線上申請，通常 1～3 週拿到。

PHASE 04 · 產品 + 安規

準備 CE / UKCA / EPR 文件

產品測試報告、DoC、授權代理人、EPR 註冊號。建議第一批只發「文件最齊」的 1～3 個 SKU。

PHASE 05 · 上架 + 發 FBA

Listing 上線、首批入倉

Flat File 批量上架、建立 Shipment、印 FBA 標籤。首批少量（200～500 件）測試流程。

PHASE 06 · 啟動銷售

廣告 + 促銷 + 收第一筆款

這一步就跨到下一份教材（№ 02 營運工具箱）的範圍了。這裡只告訴你「開站準備」到這裡結束。

Wizard 每一步都附官方連結（Amazon Seller Central / GOV.UK / EUIPO），點進去可以直接跳到申請頁面。每一步也有預估時間，讓你排開站 timeline 更準確。

D1

關鍵時間節點

第 1 天、90 天、6 個月、12 個月四個里程碑。錯過就直接失效。工具把這條時間軸畫出來提醒你。

D2

90 天加速策略

Amazon 的數據：90 天內完成 onboarding 的賣家，首年銷售高出一般賣家 6 倍。工具給你第 1~2 週、3~4 週、2~3 月三階段清單。

D3

每項如何取得 / 實用建議

點開每一個 incentive 卡片，看到「如何取得」（編號步驟）和「實用建議」（編輯本身的 Pro tips）。不是 marketing 文案，是真的可執行步驟。

debug · 常見的坑

三個最常翻車的點

✗1

「我等開完帳號再弄 EPR」

不行。沒 EPR 註冊號，你的 Listing 在 DE / FR 一定會被下架。LUCID（德國）和 Triman（法國）至少提前 1 個月申請。

EPR 必先行
✗2

「VAT 等我真的銷售了再申請」

不行。入 FBA 就得先有當國 VAT。德國 VAT 至少要 4～8 週，卡死你的首批發貨。建議開帳號同時就啟動申請。

VAT 先行
✗3

「EU4 和 UK 是同一套帳號」

帳號是同一個，但 VAT、EORI、EPR、包裝註冊、商標全部分開。新賣家大禮包也是兩份 — 別把 UK 的那份忘了申請。

兩套獨立
還是卡住？帳號還沒開的階段，最快的辦法是把卡住的情況記下來、準備好相關文件掃描檔，等帳號開通、進到 Seller Central 以後就能正式開 Case 請 Seller Support 協助。
before you move on

收工前確認這幾件事

CHECK 01
已選好目標國家

先聚焦 1～2 個主攻國家，不要一開始就打五國。DE + UK 是最常見的組合。

CHECK 02
準備清單完成度 ≥ 80%

稅務、環保、安全三大類至少跑完 8 成，再進到下一階段的帳號註冊。

CHECK 03
安規文件已發測試

CE / UKCA 至少把 DoC、測試報告、授權代理人三份文件準備齊。
